# Provider icon sources

The runtime image files in this directory are normalized from artwork served by each platform's official website. They are bundled locally so opening the Nexus importer does not make extra remote image requests. Raster assets are packaged at 256 x 256 for high-DPI displays; EA remains a resolution-independent SVG.

- Steam: the native 256 x 256 frame from `https://store.steampowered.com/favicon.ico`, served by `https://store.steampowered.com/`
- GOG: `https://www.gog.com/pressroom/wp-content/uploads/2025/06/GOG_LOGO_DARK.png`, linked from `https://www.gog.com/pressroom/press-kit/`
- Ubisoft: the 2032 x 1867 stacked black PNG in `https://staticctf.ubisoft.com/8aefmxkxpxwl/7evFGmjt94zJALDLMtedq9/7ece3bbbff176e1cb1d281ac2c5e5c47/Ubisoft_logos1116.zip`, linked as **Ubisoft Logos** from `https://www.ubisoft.com/en-us/company/press`
- EA: `https://media.contentapi.ea.com/content/dam/eacom/common/ea-wordmark-network-nav-coral.svg`, displayed by `https://www.ea.com/`

Retrieved and visually verified on August 14, 2026.
