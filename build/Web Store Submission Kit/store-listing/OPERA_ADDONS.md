# Opera Add-ons listing - 1.0.0

## Product details

- Name: `Nexus Library Importer`
- Version: `1.0.0`
- Summary: `Import supported Steam and GOG games into Nexus Mods My games.`
- Category: `Games`
- Language: `English`
- Price: `Free`

## Description

Add supported games from your PC libraries to Nexus My games without leaving the Nexus home page.

The extension places one Import button beside My games. Choose Steam or GOG, scan the library visible in Opera GX, and review the Ready, Review, Already added, and Not on Nexus groups. Steam supports the signed-in account or a public Community profile. GOG support is labeled Beta and uses the signed-in GOG account page.

Ubisoft Connect and EA are included in the platform chooser, but marked desktop-app-only because they do not currently expose an owned browser library the extension can safely read. No Ubisoft or EA account permission is requested.

Nothing is preselected. Choose individual games or Select all ready matches, and use Unselect all to clear a large selection. Nothing changes until you confirm. Imports use the native Nexus My games control one game at a time, with resumable progress and a completion summary.

A separate Manage My games panel can remove games from the list. Removal also starts with nothing selected, shows a final confirmation, and turns off only the native bookmarks the user explicitly confirms.

The interface is native to the Nexus page and does not use a browser side panel. Sign-in happens directly on the platform's website; the extension does not handle passwords or cookies.

Data is processed locally. The extension has no developer server, analytics, advertising, remote code, or data sales.
