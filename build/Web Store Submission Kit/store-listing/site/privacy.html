Privacy Policy

Nexus Library Importer - Effective August 14, 2026

Summary

Nexus Library Importer processes the data needed to match a supported PC game library with games on Nexus Mods, add only the games the user confirms, and remove only games explicitly selected and confirmed in the My games manager. Processing and storage stay inside the user's browser. The extension has no developer-operated server, analytics, advertising, remote code, or data sales.

Data handled

The extension can handle an optional Steam Community profile URL, custom ID, SteamID64, and account display name; visible Steam game names and app IDs; visible GOG game names and product IDs; games visible in Nexus My games; names and domains from the public Nexus catalog; and selected games, progress, and outcomes for the latest My games change job.

How the data is used

This data is used only to match platform titles with Nexus game pages, show matches for review, avoid adding games already present, carry out user-confirmed additions or removals, and preserve visible progress. It is not used for advertising, profiling, credit decisions, or any unrelated purpose.

Local storage and retention

chrome.storage.local stores the last selected provider, optional last resolved Steam profile URL, a cache of the public Nexus games catalog, and the latest My games change job. The catalog is refreshed after 24 hours when possible. Full scan results and removal selections remain in page memory; selected details can remain in the latest job until a later job replaces it. Removing the extension clears its extension storage.

Network requests and sharing

The browser communicates directly over HTTPS with Steam Community or GOG to load the requested library and with Nexus Mods to download its public game catalog, read My games, and operate the native bookmark control. Those services receive normal browser requests under their own privacy policies. The browser may attach existing sign-in cookies, but the extension does not read, copy, or store them. No user data is sent to the extension publisher or sold to another party.

Sign-in

Users sign in directly on the official Steam or GOG website. The extension does not host a login form and does not receive or store passwords, authentication cookies, session tokens, API keys, recovery details, or multi-factor codes.

Data not accessed

The extension does not read or store payment information, GOG orders, Steam purchases or playtime, friends, messages, health information, precise location, or general browsing history. Ubisoft Connect and EA are explanatory chooser entries only; the extension requests no access to those services.

User choices

Users choose the platform, can open its official sign-in page, review every match, start from no selection, clear a large selection, cancel a running change, clear extension data, or uninstall the extension. Removing a game requires an explicit selection in Manage My games followed by a separate final confirmation.

Limited use

User data is limited to the extension's disclosed single purpose. It is not transferred for unrelated purposes, used for personalized advertising, sold, or made available for human review.

Changes and contact

Material changes will be disclosed in the store listing and reflected here before an update is published. Privacy or support questions can be sent through the support contact shown on the extension's current web-store listing.
