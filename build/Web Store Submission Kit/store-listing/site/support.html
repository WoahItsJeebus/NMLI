Nexus Library Importer support

Version 1.0.0

Getting started

Sign in to Nexus Mods, open the Nexus home page, and select Import beside My games. Choose Steam or GOG. The importer can open the official platform library/sign-in page; finish signing in there, return to Nexus, and run the scan.

Steam cannot read the library

Steam must make the Games list visible to the account viewing it. Sign in to the same Steam account in the browser, make Game details public, or paste another public Steam profile URL, custom ID, or SteamID64.

GOG cannot read the library

Use Open GOG sign-in / library, complete sign-in on GOG, return to Nexus, and retry. GOG support is Beta because its browser library is not a documented public API. If GOG changes the account page, the importer stops rather than using incomplete results.

Why EA or Ubisoft cannot be selected

Those platforms currently expose the owned PC library through their desktop clients rather than a browser library this extension can safely read. They remain visible in the chooser so the limitation is clear, but no account access is requested.

A title needs review

Store and Nexus edition names can differ. Review matches carefully. Nothing is preselected; use Select all ready matches only when you want the full Ready group.

An import failed

Confirm that Nexus is still signed in, keep the Nexus home page open, and retry the failed title. The extension processes only one Nexus game at a time.

Remove games from My games

Open Import, choose Manage My games, search or select the games to remove, and review the final confirmation. Nothing is preselected. Cancelling stops the remaining queue, while games already processed stay removed.

Contact

Use the support contact or link on the current Chrome Web Store or Opera Add-ons listing. Include the browser name and version, platform, affected game title, and exact error. Do not include passwords, cookies, session tokens, or account secrets.
